# APK original de entrada

El flujo de GitHub Actions espera el archivo original en esta carpeta con el nombre exacto:

`input/original.apk`

Por tamaño y por tratarse de un binario, esta plantilla no incluye la APK. Colocá aquí una copia de `app-debug.apk` renombrada como `original.apk` desde el entorno donde tengas el archivo original y subila al repositorio. No reemplaces ni borres la APK original de tu teléfono.

Cuando el archivo esté en el repositorio, ejecutá **Actions → Compilar Manos Verdes Full → Run workflow**.
